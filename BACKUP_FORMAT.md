# Backup
Kompatibler JSON-Wrapper `format: "ATHLETE-OS-Backup"`, Metadaten je Export und `data` mit `schema: 4`. Neue Felder additiv (Journal, Satztypen/Drafts, Routinen-Vorgaben, Gewohnheitsrhythmus, Einstellungen, Studio-Notizen). Physische SQLite-Version 8 ist separat. Rohes V7-JSON wird ebenfalls akzeptiert. Struktur, IDs, Datumswerte, Grenzen und Mengen werden geprüft. Falsches JSON wird vor Änderung abgelehnt. Import ersetzt nach expliziter Bestätigung; der vorherige bestätigte Datensatz wird lokal gespeichert und kann wiederhergestellt werden. Kein universelles Merge, keine Verschlüsselung und keine kryptographische Backup-Prüfsumme. JSON enthält private Daten: nicht in GitHub committen oder ungewollt teilen. Native Share-/Picker- und Undo-Flow auf Gerät noch offen.
