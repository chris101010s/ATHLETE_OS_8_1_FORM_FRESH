# FORM 8.1 Fresh — no automatic migration
The fresh release opens `form-v8-fresh.db`, not the previous DEEP `form-v8.db` or the V7 KV key. On first open it initializes empty validated data and opens the optional setup screen. Existing records are not overwritten or deleted by the app. On later launches the new database is reopened. The same bundle ID is retained. Old backups can still be imported explicitly via More > Einstellungen, with confirmation and an undo snapshot in a fresh-specific key. There is no automatic migration and no automatic merge. Deinstallation is not required; if the user elects to uninstall, the OS may remove the whole old sandbox. Earlier DEEP migration design is historical, see docs/history.
